# C3・C4 が効かなかった原因の調査

E3（+C3）・E4（+C4）は E2 に対して改善しなかった（`docs/PART1_RESULTS.md`）。
`tools/diag_c3c4.py` で、テスト画像のうち COCO 由来の 2,008 枚（既知 GT 10,203 個、未知 GT 8,267 個）を診断した。
推論設定は各 config のもの（既知 `p`、未知 `o·σ(u)`、`unk_weight 0.5`）。

```bash
uv run python tools/diag_c3c4.py -c configs/e2_obj.yml -r outputs/e2_obj/best.pth
```

## 結果

| | E2 | E3 (+C3) | E4 (+C4) |
|---|---:|---:|---:|
| エンコーダが選んだ 300 候補が覆う既知 GT | 86.8% | 87.1% | **78.5%** |
| 同・未知 GT | 44.4% | 44.3% | **39.9%** |
| デコーダの最終 300 個が覆う未知 GT（順位を無視した上限） | 45.7% | 45.3% | 43.0% |
| 未知 GT のうち上位 100 件の未知検出に当たったもの | 32.5% | 31.4% | 32.2% |
| 覆っているのに上位 100 件に入らなかったもの | 13.2% | 13.9% | 10.8% |
| 未知 GT に既知クラスの検出が当たったもの | 16.2% | 16.9% | 18.0% |
| C3 が外すクエリ（既知に重ならない中で o 上位 5）が未知 GT に当たる率 | 8.4% | 9.4% | 7.5% |
| 既知に重ならないクエリ全体が未知 GT に当たる率 | 10.0% | 10.4% | 12.5% |
| 未知 GT を覆う最良クエリの o / 全クエリの o 平均 | 0.72 / 0.57 | 0.71 / 0.57 | 0.77 / 0.52 |

「覆う」は IoU ≥ 0.5。上位 100 件に関する行は、評価器の 1 対 1 マッチングをしない近似値（評価器の U-Recall とは一致しない）。

## C3 が効かなかった理由

1. **C3 が外すクエリは未知物体に当たっていない。** 既知に重ならないクエリのうち物体らしさ o の上位 5 個が未知 GT に当たる率（8.4%）は、
   同じ集合から無作為に取った場合（10.0%）と同等以下。o は「未知物体」と「背景」を未マッチのクエリの中で区別できておらず、
   C3 は実質的に無作為な 5 個を背景損失から外しているだけになっている。
2. **外しても未知スコアは変わらない。** C3 が外すのは既知クラスの分類損失（VFL）だけで、未知スコアを決める o と σ(u) には影響しない。
   影響は既知クラスの確率に出て、未知物体が既知として検出されやすくなる（16.2% → 16.9%、A-OSE 2,360 → 3,011）。

o 自体には弱い信号はある（未知を覆うクエリの o 0.72 > 全体平均 0.57）が、未マッチのクエリの上位を選べるほど鋭くない。

## C4 が効かなかった理由

1. **物体らしさによる候補選択は、クラススコアによる選択より物体を覆わない。** エンコーダの 300 候補が覆う既知 GT は 86.8% → 78.5%、
   **未知 GT も 44.4% → 39.9% に下がった**。C4 の狙い（未知物体の候補を増やす）とは逆の結果。
2. エンコーダの物体らしさは「全トークンの平均からの距離が小さい」こと。エンコーダのトークン（1 画像 8,400 個）の大半は背景なので、
   平均に近いことが物体らしさの良い指標にならない。損失は既知物体に対応するトークンを平均へ寄せるが、背景はもともと平均付近にある。
3. 候補が減った分、デコーダの最終出力が覆う未知 GT も 45.7% → 43.0% に下がった。

## 共通の観察：ボトルネックは候補生成

- デコーダの最終 300 個が覆う未知 GT は 43〜46% しかない。残りの半分以上は、どのクエリにも覆われていない。
- 覆われているのに上位 100 件に入らないのは 11〜14% で、順位付けの損失はこれより小さい。
- U-Recall を大きく上げるには、未知物体を覆う候補を増やす必要がある。C4 はその役目のはずだったが、上記の理由で候補を減らした。

## 改善の方向（未検証）

- **C4**：物体らしさ単独ではなく、クラススコアとの組み合わせ（例：既定の選択で 300 − n 個、物体らしさで n 個を追加）にする。
  あるいは、エンコーダの物体らしさの基準分布を背景が支配しないもの（例：前景トークンだけで推定）に変える。
- **C3**：外す対象を o ではなく、未知スコア o·σ(u) やエンコーダとの一致などで選ぶ。ただし o·σ(u) は背景でも高い（σ(u) は背景で ≈ 1）ため、
  まず「未マッチの中で未知物体と背景を分ける信号」があるかを確かめる必要がある。
- 未知物体を覆う候補そのものを増やす：クエリ数（300）を増やす、C5（SAM2 による疑似未知ラベル）を使う。

## 追加診断：学習なしで直せるか（`tools/diag_c3c4_signals.py`）

### C3：未マッチのクエリの中で未知物体を見分ける信号

既知 GT に重ならないデコーダのクエリ（E2: 約 50 万個、うち 10.0% が未知 GT に IoU ≥ 0.5）について、各信号が未知物体のクエリをどれだけ見分けるか：

| 信号 | AUROC（E2） | 1 画像の上位 5 個が未知物体に当たる率（E2） | AUROC（E4） | 上位 5 個（E4） |
|---|---:|---:|---:|---:|
| o（物体らしさ, 現 C3） | **0.378** | 8.4% | 0.387 | 7.5% |
| σ(u)（既知以外らしさ） | 0.573 | 7.5% | 0.603 | 9.2% |
| max p（既知クラスらしさ） | 0.454 | 18.9% | 0.454 | 19.2% |
| o·σ(u)（未知スコア） | 0.389 | 7.0% | 0.404 | 5.9% |
| 箱の面積（対数） | **0.827** | 15.9% | 0.785 | 17.6% |
| 無作為 | 0.5 | 9.1% | 0.5 | 11.2% |

- **o は未知物体と逆相関している（AUROC 0.38）。** 既知 GT に重ならないクエリの中で o が高いのは、既知物体の周辺（重なりが 0.5 未満の断片や重複）で、
  未知物体ではない。C3 は o の上位を守るので、守る対象を逆向きに選んでいる。
- 未知物体のクエリを最もよく拾うのは max p の上位（19%、無作為の約 2 倍）。これは「既知クラスに似た未知物体」で、
  背景損失から守ると既知としての誤検出（A-OSE）をさらに増やす方向に働く。C3 の考え方（既知クラスの分類損失から外す）とはかみ合わない。
- 箱の面積は AUROC 0.83 と最も強いが、「未知 GT は物体なので背景の断片より大きい」という自明な差を見ている可能性が高い。
  上位 5 個の的中率は 16% にとどまる。

→ **C3 を直す単純な信号は見つからなかった。** o を別の信号に替えるだけでは改善は見込みにくい。

### C4：クラススコアの選択に物体らしさの候補を足す

E4 の重みで、クラススコアの上位 300 に物体らしさの上位 n 個を足したときの候補の網羅率を測ろうとしたが、
**E4 のクラススコアの上位 300 は既知 GT の 5.9% しか覆わなかった**。E4 ではエンコーダのクラススコアのヘッドが、
物体らしさで選ばれたトークンだけで学習されているため、全トークンの中での順位付けができなくなっている。
このため、追加方式の効果は E4 の重みでは測れない（学習し直す必要がある）。

参考：物体らしさだけの上位 300 は既知 79% / 未知 40%（E2 のクラススコア 300 は既知 87% / 未知 44%）。
