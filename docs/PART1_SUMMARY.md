# Part I 結果報告：RT-DETRv2 による未知物体検出（M-OWODB Task 1）

2026-10-21。計画書 `docs/RT-DETRv2_OWOD.md` の Part I（未知検出エンジン M₀ の確立）の結果をまとめる。
詳細な経緯は `docs/EVAL_VALIDATION.md`、`docs/E1_POSTHOC.md`、`docs/E2_SATURATION.md`、`docs/PART1_RESULTS.md`、
`docs/C3C4_ANALYSIS.md`、`docs/NEXT_STEPS.md` を参照。

## 1. 結論

- **M₀ = F1（50 エポック）＋推論時の重複除去**（`configs/f1_quality_50ep.yml`, `outputs/f1_quality_50ep/best.pth`）。
- PROB と同じ評価器・同じテスト画像で、**Known AP50・U-Recall・WI の 3 指標で PROB を上回り、速度は約 2.3 倍**。
- M₀ の Gate（計画書 §9.2）の 3 項目をすべて満たす。
- 計画書の C3（背景損失マスキング）・C4（物体らしさによるクエリ選択）は効果がなく、採用しない。
- 外部の信号（SAM2 等の疑似ラベル, C5）を使わない方針の範囲では、改善は E2 比 +1pt 前後で頭打ちになった。
  根本の制約は「VOC の 20 クラスのラベルだけで、COCO の未知クラスの物体と背景を見分ける教師信号がない」こと。

## 3. M₀ の構成

| 部品 | 内容 | 計画書との関係 |
|---|---|---|
| 検出器 | RT-DETRv2 R50、640×640、50 エポック、fp32 | – |
| C1 既知スコア | p(c\|q) のみ | 改訂（当初は o·p。o を掛けると既知が上位 100 件の枠を未知に譲る） |
| C1 未知スコア | o·σ(u)·q | 改訂（当初は o·(1−max p)） |
| C2 物体らしさ o | 全クエリの BatchNorm（affine なし, 学習時はバッチ統計で勾配あり）からの距離、PROB と同じ | 改訂（当初は前景のみの full Σ。次元崩壊で飽和） |
| 既知以外 logit u | 未マッチのクエリを正例とする focal loss（PROB の unknown クラスと同じ） | 追加 |
| 位置の当てはまり具合 q（F1） | クラス非依存の IoU 予測ヘッド。既知 GT と IoU ≥ 0.3 のクエリだけで学習し、背景に負例なし（OLN 方式） | 追加 |
| 推論時の重複除去 | 既知の確信度 ≥ 0.1 の別クエリと IoU ≥ 0.7 で重なり、かつそのクラスの確率 ≥ 0.05 の未知を除去 | 追加 |
| 未知スコアの重み | w = 1.0 | 追加（tune 側で選択） |

## 4. 実験の経緯

### 4.1 評価器の検証（`docs/EVAL_VALIDATION.md`）

E0 の Known AP50 が文献値より 10pt 高かったため、PROB の公式重みを PROB の公式評価と本評価器の両方で採点した。
PROB の論文値（59.5 / 19.4）は再現でき、本評価器には次の 3 つの不整合があった。修正前の値は Known AP50 で約 +6pt、U-Recall で約 +6pt 甘かった。

1. テストリストの重複（1,127 枚が 2 回ずつ）の扱いが PROB と異なっていた（主因）
2. float32 のまま座標を丸めていた
3. 同点スコアの並び順が numpy のバージョンで変わる（安定ソートに変更。U-AP50 は環境で ±0.2 揺れるため文献比較に使わない）

### 4.2 Part I の実験（計画書の E0〜E4）

| 実験 | 内容 | Known AP50 | U-Recall | 結果 |
|---|---|---:|---:|---|
| E0 | 閉集合 | 64.51 | 0 | 基準 |
| E1 | E0 + post-hoc Mahalanobis | 64.41 | 16.81 | 学習なしの下限 |
| E2 | C1 + C2 | 62.59 | 20.58 | PROB 方式に改訂後、PROB を上回る |
| E3 | + C3 | 62.69 | 20.31 | 改善なし |
| E4 | + C4 | 61.75 | 19.94 | 改善なし |

（テスト全体、`unk_weight 0.5`。）

### 4.3 E2 以降の改良（外部の信号なし）

| 案 | 内容 | 結果 |
|---|---|---|
| 未知スコアの重み | 未知スコアを w 倍して既知との枠の取り合いを調整 | 採用（Known AP50 +10pt、U-Recall ほぼ維持） |
| 未知の枠の上限 | 上位 100 件のうち未知を n 件まで | 不採用（U-Recall が大きく下がる） |
| A/B/C | 反転の一貫性、既知らしいが既知でないスコア | 不採用（+0.2 以下） |
| V1 | モデル自身の予測からの疑似未知ラベル（自己学習） | 不採用（精度は最大 17.5%、イテレーション単位でも同様） |
| V2 | 推論時のクエリ数を増やす | 不採用（候補は増えるが U-Recall は上がらない） |
| F1 | 位置の当てはまり具合ヘッド | **採用** |
| F2 | 既知物体の重複を σ(u) の負例に | 不採用（U-Recall −4.5） |
| 重複除去 | 推論時に既知の検出と重なる未知を除去（IoU + クラス一致） | **採用** |
| F3 / F3b / F3c | 既知クラスの一部を未知に見立てる学習 | 不採用（背景は強く抑えるが U-Recall は上がらず、50 エポックでは検出器が弱くなる） |

## 5. 分かったこと

1. **PROB の物体らしさは「全クエリを基準にした分布」で作る必要がある。** 前景だけを基準にすると、正例のみの損失が埋め込みを低ランクに潰し（256 次元中 199 次元が下限に張り付き）、全クエリの物体らしさが飽和する。
2. **未知の取りこぼしの主因は、候補の数ではなく「未知物体と背景の見分け」。** デコーダの候補が覆う未知物体は約 45% だが、クエリを増やして 66% まで覆っても U-Recall は上がらない。増えた候補は上位 100 件に入らない。
3. **物体らしさ o は、未マッチのクエリの中では未知物体と逆相関する（AUROC 0.38）。** o が高いのは既知物体の周辺の断片や重複。C3・C4 は「o で未知物体を見つける」前提のため機能しなかった。
4. **未知の検出の上位を占めるのは、既知物体の重複・断片と背景。** E2 では上位 5 件のうち未知物体は 7%。M₀ では 20% まで改善したが、既知の重複（約 4 割）と背景（約 3 割）が残る。
5. **DETR の重複クエリはクラス確率が 0 近くまで下がる**ため、クラスの確率では「既知物体の重複」と「既知と誤認された未知物体」を見分けられない。重複除去で空いた枠は背景で埋まる。
6. **既知クラスを未知に見立てる学習（F3）は背景を強く消すが、COCO の未知クラスへの再現率は上がらない。** VOC の 20 クラスから学んだ物体らしさは、食べ物・小物などの未知クラスに十分汎化しない。

## 6. 注意点と限界

- **すべて 1 回の学習の結果。** シード違いのばらつきは測っていない（V6 は行わない判断）。E2・F1・F3 系の差は 1pt 前後で、偶然の範囲の可能性がある。
- **推論設定（未知スコアの重み・重複除去の閾値）はテスト画像の半分で選んだ。** report 側の値はこの選択に使っていないが、M-OWODB の正式な分割ではない。論文等で使う場合はこの手順を明記する。
- **A-OSE は PROB より多い**（report 側 4,040 vs 2,631）。重複除去で未知の検出を落とした場所に、既知クラスの検出が残るため。
- **速度比は約 2.3 倍**で、計画書の想定（5〜10 倍）には届かない。PyTorch eager での比較で、TensorRT 等の最適化は未計測。
- 評価は Task 1 のみ。Task 2〜4（増分学習）は未実施。
